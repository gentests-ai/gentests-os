# Inspeção X9 — Fluxo enxuto

1. Agendamento ou alteração no GitHub dispara verificações técnicas.
2. X9 consolida achados e registra apenas alertas fundamentados.
3. AGT-VAL verifica fontes, relevância, gravidade e ocorrência real.
4. Se confirmado, registrar RNC e atribuir ao agente executor.
5. Executor corrige; AGT-VAL revalida; Auditor revisa amostras.

**Regra:** alerta não é uma RNC; não duplicar notificações ou reabrir problemas encerrados sem nova evidência.
